> **Planned Feature** — The Enterprise API is in development. This section documents the planned API surface for platform integrators. Endpoints and schemas may change before launch.

## Overview

The RTP Enterprise API lets launchpads offer RTP treasury infrastructure to their token creators via a simple REST API. Your platform adds an "Enable RTP Treasury" button, and the Enterprise API handles PDA creation, fee routing configuration, and treasury state queries — no SDK installation or Solana wallet management required on your end.

### How It Works

1. **Your platform** adds an "Enable RTP Treasury" option for token creators
2. **Token creator clicks enable** — your frontend calls the Enterprise API
3. **Enterprise API** creates the treasury PDA, vault PDA, and adopter record on-chain
4. **Enterprise API** configures fee routing to the treasury PDA
5. **RTP swarm** begins monitoring the treasury and executing yield strategies
6. **Yield flows back** — 70% to holders, 20% to project dev, 10% to ecosystem

**Base URL:** `https://api.resilientprotocol.com` (planned)

## Authentication

All requests require an API key in the `Authorization` header:

```
Authorization: Bearer rtp_live_abc123...
```

API keys are issued per launchpad. Contact the RTP team to register.

## Endpoints

### Register a Token

```http
POST /v1/adopt
```

Registers a token with RTP. Creates the treasury PDA, vault PDA, and adopter record on-chain.

**Request:**

```json
{
  "mint": "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
  "platform": "pumpfun",
  "name": "Community Token",
  "symbol": "CMTY",
  "holdersWallet": "ABCx...1234",
  "projectDevWallet": "ABCx...1234",
  "ecosystemWallet": "ABCx...1234",
  "feeRouting": {
    "type": "keeper",
    "deployerWallet": "ABCx...1234"
  }
}
```

**Response:**

```json
{
  "treasuryPDA": "7oZTJWYBDjzqmbfRs5YkTv53CDa6vESAzfyjK3yhYshc",
  "vaultPDA": "9xRWo1N4xjyUN3fbmRpUVwP4WQcEPakdECThyx93CxkR",
  "adopterPDA": "7zSW...abcd",
  "signature": "5Kq8...xyz",
  "explorerUrl": "https://explorer.solana.com/tx/5Kq8...xyz?cluster=mainnet-beta"
}
```

### Configure Fee Routing

```http
POST /v1/fee-route
```

Configures platform-specific fee routing to the RTP treasury. Platform-specific logic handled server-side.

**Request:**

```json
{
  "mint": "EPjFWdd5...",
  "platform": "bags",
  "config": {
    "feeClaimers": [
      { "user": "7oZTJWYBDjzqmbfRs5YkTv53CDa6vESAzfyjK3yhYshc", "userBps": 7000 },
      { "user": "ABCx...1234", "userBps": 3000 }
    ]
  }
}
```

**Response:**

```json
{
  "signature": "3HzW...def",
  "feeShareConfigured": true,
  "claimers": 2
}
```

### Get Treasury State

```http
GET /v1/treasury/:mint
```

Reads the on-chain treasury state for a token. No authentication required.

**Response:**

```json
{
  "mint": "EPjFWdd5...",
  "phase": "Sustenance",
  "vaultBalance": 1250.5,
  "totalFeesWithdrawn": 3200.0,
  "totalDistributedHolders": 2240.0,
  "totalDistributedDev": 640.0,
  "totalDistributedEcosystem": 320.0,
  "totalHydration": 180.0,
  "minRunwayBalance": 10.0
}
```

### Trigger Crank

```http
POST /v1/crank
```

Triggers the permissionless crank: withdraw fees + redistribute if above threshold.

**Request:**

```json
{
  "mint": "EPjFWdd5..."
}
```

**Response:**

```json
{
  "withdrawSig": "4Kq8...abc",
  "redistributeSig": "5Kq8...def",
  "distributed": {
    "holders": 224.0,
    "dev": 64.0,
    "ecosystem": 32.0
  }
}
```

### End Beta

```http
POST /v1/beta/end
```

Ends a beta adopter's RTP participation. Only callable by the treasury authority.

**Request:**

```json
{
  "mint": "EPjFWdd5..."
}
```

**Response:**

```json
{
  "signature": "6Kq8...ghi",
  "betaEnded": true
}
```

## Error Codes

| Code | Meaning |
|------|---------|
| `400` | Invalid request body or missing fields |
| `401` | Missing or invalid API key |
| `404` | Token not registered with RTP |
| `409` | Token already registered |
| `500` | On-chain transaction failed |

## SDK vs Enterprise API

| Feature | SDK (Direct) | Enterprise API |
|---------|-------------|----------------|
| Signing | Your wallet | RTP-managed |
| Chain ops | Your infra | RTP infra |
| Latency | Direct | ~200ms overhead |
| Cost | Gas only | Gas + service fee |
| Control | Full | Delegated |
| Setup | More code | HTTP calls |
| Best for | Full control | Simple integration |

Use the SDK if you want full control over signing and chain operations. Use the Enterprise API if you prefer a simple HTTP API without managing wallets or Solana connections.
